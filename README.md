# Focus Coach

A Windows homework session that watches the active window, uses the webcam to see if you are at the desk, and checks a photo of your work when you ask.

Double-click `run.bat` to start it. The first launch installs a local Python environment.

During a session the camera preview stays on screen, and window titles stay on this PC. **Check my work** uses the local Ollama model `qwen3.5:9b`, then unloads it.
